# Catalogues embarqués

Ce répertoire accueillera les ensembles de données versionnés et livrés avec l'application.

Découpage cible :
- `resources/` — biens et ressources ;
- `buildings/` — bâtiments ;
- `production/` — recettes et flux ;
- `population/` — paliers, résidences et besoins ;
- `regions/` — régions et caractéristiques ;
- `island-availability/` — fertilités et gisements disponibles par île.

Les ensembles seront reliés par des identifiants stables et décrits par un manifeste commun.

**État initial :** aucun jeu de données de production n'est encore publié dans ce répertoire. Les inventaires communautaires examinés sont des pistes de vérification uniquement. Les premières valeurs ne seront ajoutées qu'après observation ou expérimentation propre au projet, avec leur statut et leur provenance interne.
