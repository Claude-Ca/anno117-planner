# Carnet de vérification du catalogue — Anno 117: Pax Romana

> **But :** consigner les observations réalisées dans le jeu pour vérifier le catalogue d'Anno 117 Planner. Remplir uniquement les champs connus. Écrire `inconnu` ou laisser vide plutôt que de deviner.
>
> **Périmètre :** jeu de base, Latium et Albion. Ne pas inclure les DLC dans cette campagne de validation.

## Comment remplir ce carnet

1. Faire une copie de ce fichier pour chaque session, ou ajouter plusieurs relevés à la suite.
2. Pour chaque observation, noter le nom affiché dans le jeu, la valeur exacte et son unité.
3. Indiquer les conditions susceptibles de modifier la valeur : bonus, amélioration, vitesse de jeu, population, niveau de satisfaction, etc.
4. Distinguer ce qui est **lu directement dans le jeu** de ce qui est **calculé ou déduit**.
5. Si possible, joindre une capture d'écran à la conversation quand tu me transmets le carnet. Elle n'est pas obligatoire.

### Codes de statut proposés

- `observed` : constaté directement dans le jeu, mais pas encore recoupé.
- `verified` : vérifié et cohérent avec les autres relevés.
- `disputed` : contradictoire ou dépendant d'une condition à clarifier.
- `to-observe` : information à rechercher.
- `not-applicable` : élément non applicable au cas testé.

Ne modifie pas le statut technique du catalogue dans ce carnet : je ferai la consolidation après analyse.

## 8. Première campagne recommandée

Pour que les premiers relevés aient un impact maximal, commence par les informations faciles à retrouver et structurantes pour le moteur :

1. **Paliers d'habitation** présents sur l'île et nombre d'habitants par habitation.
2. **Liste des besoins** affichés pour chaque palier, en notant les différences entre Latium et Albion.
3. **Pour un ou deux besoins simples**, identifier le bâtiment qui produit le bien correspondant et relever sa cadence de base.
4. Noter les bonus ou conditions visibles, mais ne pas chercher à tous les tester dès la première session.
5. Signaler les éléments impossibles à vérifier ou les valeurs qui semblent ambiguës.

Il n'est pas nécessaire de compléter toutes les sections lors d'une seule session. Quelques relevés précis sont plus utiles qu'un grand nombre de valeurs incertaines.
