# Documentation fonctionnelle

Ce répertoire décrit le besoin produit et les comportements attendus, indépendamment de leur implémentation technique.

- [Expression de besoin](expression-de-besoin.md) — finalité, périmètre et besoins initiaux du produit.
- [Cadrage de la première interface de planification](cadrage-interface-planification.md) — état du dépôt, contrat applicatif, écarts et décisions à arbitrer pour le lot 5.

Les spécifications détaillées, règles de gestion et critères d'acceptation seront ajoutés ici à mesure qu'ils seront formalisés. Les décisions transverses restent centralisées dans [le registre de gouvernance](../00-gouvernance/registre-decisions.md).
