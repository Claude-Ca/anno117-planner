# Documentation du projet

La documentation d'Anno 117 Planner est organisée par domaine. La [politique documentaire](00-gouvernance/politique-documentaire.md) définit les conventions de classement, les statuts et les critères de qualité.

| Domaine | Répertoire | Rôle |
|---|---|---|
| Gouvernance | [00-gouvernance](00-gouvernance/README.md) | Décisions, règles documentaires et revues |
| Fonctionnel | [10-fonctionnel](10-fonctionnel/README.md) | Besoin et comportement attendu |
| Technique | [20-technique](20-technique/README.md) | Architecture, contrats et données |
| Plans | [30-plans](30-plans/README.md) | Lots, jalons et pilotage |
| Manuel | [40-manuel](40-manuel/README.md) | Installation et guides pratiques |
| Archives | [90-archives](90-archives/README.md) | Documents historiques remplacés, le cas échéant |

## Principes
- Les décisions validées sont centralisées dans le registre de gouvernance.
- Les spécifications fonctionnelles expriment le besoin ; les contrats techniques décrivent les engagements de conception.
- Les plans distinguent le travail prévu de l'avancement vérifié.
- Les guides décrivent des procédures reproductibles.
- Les documents de données distinguent couverture, provenance et droits de réutilisation.
